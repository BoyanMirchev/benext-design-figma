# BeNeXt Figma Design Recreation

Frontend-only Next.js recreation based on the supplied BeNeXt Figma design and exported reference screens.

## Start locally (Windows PowerShell)

```powershell
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:3000`.

## Pages
- `/` — Homepage
- `/services` — Services
- `/projects` — Projects
- `/contacts` — Contacts
- `/projects/aunature`
- `/projects/madix`
- `/projects/farm-academy`
- `/projects/kesh`

No backend or form submission logic is included. The project is intentionally frontend/design-only so it can be continued in v0 or VS Code.
